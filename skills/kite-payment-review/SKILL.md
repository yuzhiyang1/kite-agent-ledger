# 审查支付证据

1. 从 CLI 或 Python 调用入口追到 SQLite 和报告，确认 HTTP 结果、服务报告和链上核验各有独立字段。HTTP 成功、缺少凭证、RPC 超时和链上已确认要分别有测试。
2. 对 `confirmed` 检查 Kite 测试网链 ID、交易哈希、成功状态、官方代币合约、付款方、收款方和最小单位金额。多条同向转账、有冲突的哈希或不确定的 RPC 返回都要有保守状态。
3. 检查调用 ID 幂等和交易哈希唯一性是否仍由事务保障。核对重复导入、写入失败、并行捕获和后续补充哈希时的记录与历史。
4. 检查新增字段和日志，只记录审计所需元数据。钱包私钥、签名授权、原始头、请求体、真实个人信息和 RPC 凭据留在调用方。
5. 把本地模拟、公开历史交易回查和实际支付联调分别记录。审查报告给出证据路径、命令、实际结果及任何未验证条件。
